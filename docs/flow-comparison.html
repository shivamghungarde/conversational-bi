Where the video's approach is stronger

  • It can try any question the schema supports, including joins nobody modelled.
  • Setup is minutes: no definitions to write before the first answer.
  • For open-ended exploration, an agent that keeps querying finds angles a fixed driver analysis won't.

Worth borrowing

  • A guarded fallback: when the semantic model can't answer, a local LLM drafts SQL that must pass a read-only, allow-listed check, clearly labelled as unverified.
  • A “show steps” toggle alongside the SQL we already show, listing each step the engine took.
  • Connecting to a real Postgres instance as the demo source, as the video does.

The video is a beginner tutorial; the presenter lists guardrails, LangGraph workflows and deployment as later course topics, so its flow reflects a teaching build, not a finished product.
